## 📌 About The Project

Stopwatch is a simple and interactive web application built using HTML, CSS, and JavaScript. It allows users to measure elapsed time with hours, minutes, seconds, and milliseconds. Users can start, stop, and reset the stopwatch using interactive buttons. The timer updates continuously to display the elapsed time.

## ✨ Features

- Start the stopwatch.
- Stop and pause the timer.
- Reset the stopwatch to zero.
- Display hours, minutes, seconds, and milliseconds.
- Update the timer every 10 milliseconds.
- Prevent multiple timers from running simultaneously.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Click the Start button to begin timing.
5. Click Stop to pause the stopwatch.
6. Click Reset to return the timer to zero.
